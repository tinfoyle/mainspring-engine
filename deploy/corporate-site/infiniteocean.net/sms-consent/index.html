Spyglass account security

SMS Security Consent

A user can choose a passkey, a text message, or an email code during account setup. Choosing text messages does not subscribe the user to marketing.

How a user opts in

  1. Sign up for or sign in to Spyglass.
  2. Choose Text message from two-factor authentication setup.
  3. Enter a U.S. mobile number.
  4. Read and check the separate, unchecked consent box.
  5. Select Send my code.

The button remains unavailable until the user checks the box. Passkey and email-code options remain available.

Text message · Step 2 of 3

What mobile number should we use?

We will send a 6-digit code to confirm the phone is yours.

What users receive

Messages contain a one-time Infinite Ocean security code. Message frequency varies with sign-in and security activity. Standard message and data rates may apply. Reply STOP to opt out or HELP for help.

We do not send marketing through this program. Read our Privacy Policy and Terms and Conditions, or email support@infiniteocean.net.
